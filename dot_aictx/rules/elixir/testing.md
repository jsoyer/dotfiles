# Elixir Testing

> This file extends [common/testing.md](../common/testing.md) with Elixir-specific content.

## Test Framework

- **ExUnit** is built in — no installation needed
- **Mox** for mock-based testing of behaviours (`{:mox, "~> 1.0", only: :test}`)
- **Bypass** for mocking HTTP servers in integration tests

## ExUnit: describe/test Blocks

```elixir
defmodule MyApp.AccountsTest do
  use ExUnit.Case, async: true

  alias MyApp.Accounts

  describe "create_user/1" do
    test "creates user with valid attributes" do
      attrs = %{email: "alice@example.com", name: "Alice", password: "secret1234"}
      assert {:ok, user} = Accounts.create_user(attrs)
      assert user.email == "alice@example.com"
    end

    test "returns error changeset with invalid email" do
      attrs = %{email: "not-an-email", name: "Bob", password: "secret1234"}
      assert {:error, changeset} = Accounts.create_user(attrs)
      assert "has invalid format" in errors_on(changeset).email
    end
  end
end
```

Set `async: true` whenever tests do not share global state (no database writes, no process registry).

## Database Tests with Ecto Sandbox

```elixir
defmodule MyApp.AccountsTest do
  use MyApp.DataCase  # sets up Ecto sandbox

  # DataCase (generated by phx.new) wraps each test in a transaction
  # that is rolled back after the test — no cleanup needed.
end

# test/support/data_case.ex (generated, shown for reference)
defmodule MyApp.DataCase do
  use ExUnit.CaseTemplate

  using do
    quote do
      alias MyApp.Repo
      import Ecto.Changeset
      import MyApp.DataCase
    end
  end

  setup tags do
    pid = Ecto.Adapters.SQL.Sandbox.start_owner!(MyApp.Repo, shared: not tags[:async])
    on_exit(fn -> Ecto.Adapters.SQL.Sandbox.stop_owner(pid) end)
    :ok
  end
end
```

## Doctest

Embed tests directly in `@doc` examples — ExUnit runs them automatically:

```elixir
@doc """
Formats a price in cents as a currency string.

## Examples

    iex> MyApp.Format.currency(1050, :usd)
    "$10.50"

    iex> MyApp.Format.currency(0, :eur)
    "€0.00"

"""
def currency(cents, :usd), do: "$#{format_decimal(cents)}"
def currency(cents, :eur), do: "€#{format_decimal(cents)}"
```

Enable in `test/test_helper.exs`: `doctest MyApp.Format` inside the test module, or globally via `ExUnit.configure([:doctest])`.

## Mox for Mocking

Define the mock in `test/support/mocks.ex`, configure it in `test_helper.exs`:

```elixir
# test/support/mocks.ex
Mox.defmock(MyApp.MockMailer, for: MyApp.Mailer)

# test/my_app/notifications_test.exs
defmodule MyApp.NotificationsTest do
  use ExUnit.Case, async: true
  import Mox

  setup :verify_on_exit!

  test "sends welcome email on signup" do
    expect(MyApp.MockMailer, :send, fn "alice@example.com", "Welcome!" -> :ok end)
    assert :ok = MyApp.Notifications.welcome("alice@example.com")
  end
end
```

## Async Tests

- Mark `async: true` when tests don't share mutable state
- Database tests: use `Ecto.Adapters.SQL.Sandbox` with `shared: not tags[:async]`
- GenServer tests: start under `start_supervised!/1` — automatically stopped after test

## Test Commands

```bash
mix test                            # Run all tests
mix test test/accounts_test.exs     # Single file
mix test test/accounts_test.exs:42  # Single test by line
mix test --only integration         # Run tagged tests
mix test --cover                    # Coverage (requires :excoveralls or built-in)
mix coveralls.html                  # HTML coverage report (excoveralls)
```
